# KBO Pitcher Data Analysis

- 웹 대시보드: https://kbo-pitcher-data-analysis.streamlit.app/

투수-타자 맞대결 시뮬레이터를 기반으로 한 PAI(Pitcher Assessment Index) 개발 프로젝트입니다. 초기 가중치와 최적화된 가중치 모델을 비교하여 ERA* 예측력을 향상시키고, 2025년 데이터를 통해 실전 예측력을 검증합니다.

PAI-Simulator: Machine Learning-Based Pitcher Assessment Index
A data-driven project to quantify pitcher value through a Pitcher-Batter Matchup Simulator and machine learning-based weight optimization. 

Project Overview
The PAI (Pitcher Assessment Index) project aims to develop a comprehensive metric for pitchers, similar to wRC+ for batters. By simulating matchups based on KBO (Korea Baseball Organization) data, we derived optimized weights for pitching events to provide a more accurate evaluation of a pitcher's true skill.
